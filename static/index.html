Подключение Last.fm

Нужен API key из Last.fm API Account. Ключ сохраняется только в локальном хранилище этого браузера и передаётся приложению при запросе. Используйте интерфейс в доверенной сети или через HTTPS: при обычном HTTP ключ передаётся без шифрования. Для перечисленных методов авторизация пользователя Last.fm не требуется.
