Подключение личного аккаунта Last.fm

Для персональных рекомендаций Last.fm нужно подтвердить доступ приложения к аккаунту. Введи API key и Shared Secret со страницы API Account. Пароль Last.fm приложению не нужен.

1. Открыть Last.fm и разрешить доступ Аккаунт не подключён.

После подключения API key, Shared Secret и session key сохраняются в файле /data/lastfm_credentials.json внутри контейнера. В Compose для этого используется локальная папка ./data, исключённая из Git.
