# slskd Song Queue

HTTP-сервис с веб-интерфейсом: принимает список композиций, ищет совпадения через API соседнего контейнера `slskd` и добавляет выбранные файлы в очередь загрузок. Интерфейс показывает статусы и прогресс загрузки с автоматическим обновлением.

## Быстрый запуск

1. Скопируйте пример переменных окружения:

   ```bash
   cp .env.example .env
   ```

2. Запустите контейнеры:

   ```bash
   docker compose up -d --build
   ```

3. Откройте slskd: http://localhost:5030, завершите первичную настройку Soulseek и создайте API key в настройках Web/API.
4. Укажите ключ в `.env`:

   ```dotenv
   SLSKD_API_KEY=your_api_key
   ```

5. Пересоздайте контейнер приложения:

   ```bash
   docker compose up -d --build song-queue
   ```

6. Откройте веб-интерфейс: http://localhost:8080.

Проверка API: `curl http://localhost:8080/health`. Swagger UI: http://localhost:8080/docs.

## Использование

Вставьте по одной композиции на строку в формате `Исполнитель — Название`, `Исполнитель - Название` или `Artist / Title`. Нажмите «Найти и скачать». Для каждого трека приложение запустит поиск, оценит совпадения и передаст выбранный файл в очередь slskd. Состояния и прогресс обновляются автоматически примерно раз в 1,5 секунды.

Можно отправлять список через API:

```bash
curl -X POST http://localhost:8080/songs \
  -H 'Content-Type: application/json' \
  -d '{"songs":[{"artist":"Daft Punk","title":"Giorgio by Moroder"},{"artist":"Massive Attack","title":"Teardrop"}]}'
```

Основные endpoints:

- `GET /health` — состояние сервиса.
- `POST /songs` — создать batch поиска.
- `GET /batches/{batch_id}` — получить статусы и прогресс треков.

## Конфигурация

| Переменная | Назначение |
|---|---|
| `SLSKD_URL` | URL slskd внутри Docker-сети, по умолчанию `http://slskd:5030` |
| `SLSKD_API_KEY` | API key из настроек slskd |
| `SEARCH_TIMEOUT_MS` | Таймаут поиска, мс |
| `POLL_INTERVAL` | Интервал опроса состояния поиска, секунды |
| `MAX_WAIT_SECONDS` | Максимальное ожидание результатов поиска |
| `MIN_MATCH_SCORE` | Минимальная оценка совпадения от 0 до 1 |
| `MAX_RESULTS_PER_SONG` | Лимит результатов поиска на трек |
| `TRANSFER_POLL_INTERVAL` | Интервал опроса трансферов, секунды |
| `TRANSFER_MONITOR_HOURS` | Максимальное время мониторинга загрузки, часы |

## Важные замечания

- Сервис не скачивает файлы самостоятельно, а передаёт выбранные результаты в очередь slskd.
- Состояние batch хранится в памяти процесса. После перезапуска `song-queue` история batch не восстанавливается, но сами трансферы продолжают управляться slskd.
- Реализация ориентирована на API slskd; названия полей и формы ответов могут зависеть от версии. При несовпадении проверьте API вашей сборки slskd.
- Не публикуйте порты приложения и slskd в интернет без аутентификации и сетевой защиты. Не добавляйте `.env` или API key в Git.
- Соблюдайте законодательство об авторском праве и правила Soulseek.
